日期：2026-10-22

## 一、一句话结论

**技术上能查到真实余额，但无法做到无人值守。** 项目停在「半自动」：需要有人用微信打开小程序，
其余（查询、记账、预测、告警、定时）全部自动。因使用者主要用手机微信、且无闲置安卓设备，
**当前不建议继续投入自动化**。

---

## 二、已确证的技术事实（都有实测依据）

| 项目 | 结论 |
|---|---|
| 接口 | `POST https://shoucard.shou.edu.cn/openservice/miniprogram/queryroominfo` |
| 认证 | 请求头 `sw-Authorization: Bearer <JWT>` |
| 余额字段 | `data.restElecDegree`（元） |
| 请求体 | `{"elcsysid":"1","areaid":"1","roomid":"11010610","buildid":"1"}` |
| 证书固定 / 请求签名 / 响应加密 | **均无** |
| 网络 | 仅校园网可达（`shoucard.shou.edu.cn` → `172.18.3.170`） |
| token 有效期 | **2 小时**（JWT，`exp - iat = 7200s`），服务端不续发 |
| 换 token 的条件 | `POST /openservice/wechatauth/token`，body 需 `{code, stuempno}` |

### 为什么学号+密码不能换 token

服务端的用户主键是**微信 openid**，学号只是绑定在 openid 上的附属信息。CAS 登录只能证明「你是这个学生」，
产生站点会话；查询接口不认会话，只认 JWT。

三次实测证明：

| 尝试 | 结果 |
|---|---|
| CAS 会话 Cookie 直接查 queryroominfo | 403 |
| 空 `code` + 学号 + CAS 会话 | `code:不能为空` |
| 复用旧 `code` + 学号 + CAS 会话 | `请求微信平台失败`（服务端去微信核验） |

`code` 只能由微信客户端实时生成、一次有效。**没有任何办法在树莓派上凭空造出 code。**

### 已尝试并否定的自动化路径

| 路径 | 结果 |
|---|---|
| 纯服务器 / 树莓派 | 不可行（拿不到 code） |
| PC `weixin://` 深链唤醒小程序 | 仅「微信完全关闭后由深链拉起」时有效，3 次成功 1 次；需杀微信，不可接受 |
| 安卓机抓包取 token | 安卓 7+ 不信任用户证书，通常需 root |
| 常驻微信 + UI 自动化 | 唯一可行方向，但需要专用设备 |

## 三、什么条件下值得重启

满足任意一条再考虑：

1. **有一台闲置安卓手机**（可长期插电、不用于日常）：用 ADB 定时打开小程序并读取界面上显示的余额，
   不碰证书、不碰 token。这是目前最现实的全自动方案。
2. **学校开放了查询 API 或网页端电费查询**：若网页端接受 CAS 会话（CAS 登录无验证码、密码 RSA 加密，
   可程序化），树莓派方案立刻复活，完全不依赖微信。
3. **出现免微信的第三方入口**（后勤平台、能源管理平台等）。

重启前先做的验证：浏览器登录学校网页端，确认是否存在能显示「寝室余额」的页面。有 → 有戏；没有 → 别折腾。

## 五、日常操作（半自动）

```powershell
# 每次开新终端都要设（或直接用 scripts\run-once.ps1）
$env:PYTHONPATH = "src"

# 纯查询，写库，不推送
python -m rest_electric once --no-notify

# 试运行：不写库、不推送，只验证接口通不通
python -m rest_electric once --dry-run

# 看 token 还剩多久（不联网、不消耗额度）
python -m rest_electric token-status

# 本地报表（不推送、不消耗额度）
python -m rest_electric report --days 14

# 手动推送到微信（消耗 1 条 Server酱额度）
python -m rest_electric report --days 7 --push

# 只测推送通道（消耗 1 条额度）
python -m rest_electric selftest --send-test

# token 过期后刷新（推荐）：一键完成开关代理与收尾，你只需打开小程序
.\scripts\refresh-token.ps1

# 手动方式：开代理 → 启动带插件的 mitmweb → 打开电脑微信里的小程序 → 恢复正常上网
.\scripts\proxy-on.ps1
.\scripts\start-mitmweb.ps1
.\scripts\proxy-off.ps1
```

### Server酱额度

免费版一般 5 条/天。系统内做了冷却，避免重复消耗：

- 同类告警（余额低 / 预计欠费 / 登录失效 / 查询失败）每天最多 1 条；
- 测试、报表推送、自检各占 1 条；
- 纯查询（`once --no-notify` / `--dry-run`）和 `report` 不消耗额度。

若额度紧张：日常只用 `--no-notify` 记数据，需要时再 `report --push`。
